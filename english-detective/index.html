# 風雨中的英文偵探｜SDD 與使用說明

版本：1.0｜2026-10-26｜依七張 Lesson 5 教材照片設計。

## 使用方式
下載 English_Detective.html，使用 Chrome、Edge、Firefox 或 Safari 開啟。手機若檔案預覽器不執行 JavaScript，改用瀏覽器開啟，或將整份 HTML 貼入 Gemini Canvas 並請其預覽。此檔案不會自動建立 Gemini Canvas 專案。

固定題庫、內建 SVG、三階提示、音效和報告無需網路。四個主線關卡共 16 題；44 詞條可獨立巡查或與主線合併練習。完整模式共 60 題，約需 25–40 分鐘。重開或重新整理分頁會失去本局紀錄；結案時可匯出 CSV 或文字報告。

## 教學範圍與驗收條件
- 感官動詞後原形與 V-ing、反身代名詞、not only…but also、both…and、日期、課文時間與因果。
- 44 詞條依教材字彙頁；一個詞條含多個詞義或變化時，以同一張卡呈現。
- 原形／V-ing 題以「指定語意焦點」設問，避免聲稱另一種形式不合文法。Q7 文字輸入接受 move、moving，不分大小寫。
- Q13 與 Q15 採點選排列，可點已放入卡片撤回；其他題採文字輸入或四選一。
- 有錯誤或曾要求提示的題進入重練池。重練為相同題幹重新排列選項，屬於訂正練習，不能視為新情境遷移測驗。
- 首次答對率只計「未使用提示且第一次作答正確」；AI 助教也視為使用提示。

## 狀態機
INIT_SCREEN → PLAYING_STATE → SCAFFOLD_MODAL → PLAYING_STATE。
主線結束且存在錯題／提示題時 → MASTERY_RETRY_STATE → DIAGNOSTIC_REPORT。
結算可手動再練未獨立訂正題；回首頁須確認放棄當局。沒有生命值與倒數計時。

## 資料結構
Question: id, node, p, opts, answer, hints[3], scene, type(choice/text/order), alt。
choice 的正確答案為原始 opts[0]，畫面會打亂順序；order 的原始 opts 為正確順序；text 用 alt 陣列比對。
Session: name, mode, qs, idx, phase, retry, records, started, vseen。
Record: id, node, firstCorrect, errors, hints, retryPassed, attempts, answerText, ms。
使用者暱稱、API Key 與紀錄僅存在目前分頁記憶體，沒有自動儲存或後端。

## 鷹架與回饋
第一次：概念線索。第二次：結構提示。第三次：完整解析，標記待複習並允許繼續。
正確：顯示概念解析、播放可關閉的合成音效。錯題再次出現時須獨立答對才標記 retryPassed。
文字提示不是 modal 視窗，使用 aria-live 狀態區，避免打斷鍵盤焦點。

## 外部服務與離線策略
Gemini：POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent。
預設 gemini-2.5-flash；可在首頁選用設定修改。使用 x-goog-api-key 標頭；不依賴任何平台自動注入金鑰。只傳當題或匿名統計，暱稱不傳。
請求最長每次 12 秒，最多三次，重試等待 1、2 秒。非暫時性 4xx 直接降級；無金鑰時立刻使用固定提示／內建延伸題。
AI 助教提供引導；AI 複習建議提供匿名紀錄講評；AI 再出 3 題使用 JSON schema 與本地型別驗證。僅結構檢查不等於內容正確，因此額外題不計入固定成績，頁面明示未經教師審核。

Wikimedia：Commons action=query / generator=search / namespace=6 / imageinfo url|extmetadata，圖片旁顯示作者、授權與來源連結。
DiceBear：9.x/adventurer/svg，固定非個人化 seed。
Pollinations：image.pollinations.ai/prompt 路徑作選用來源，可能因服務授權政策失效；不保證免金鑰服務可用。
預設不連線取圖，選用時才送出情境關鍵字。補充圖片不作為答題判斷依據。
圖片載入失敗或超過五秒使用內建 SVG；主舞台一開始就顯示內建 SVG，外部取圖不阻擋遊玩。

## 介面與匯出
桌面左右分欄，720px 以下上下排列，按鈕至少 48px。純 CSS 提供完整樣式，不依賴外部樣式載入。鍵盤可操作選項與排列卡片。
CSV 為 UTF-8 BOM，逐欄加引號並處理公式起始字元。文字報告另可下載或複製。各概念顯示首次答對率，不以提示後的正確結果灌入首次正確率。

## 限制
驗證結果：JavaScript 語法檢查與 DOM 自動化測試通過，涵蓋 16 題主線、44 詞條、三階提示、排列題、文字接受 move、錯題重練、CSV／文字下載觸發及離線延伸題。瀏覽器執行檔無法下載，因此未完成實際瀏覽器畫面檢視或手機觸控驗證。

不提供發音評量或錄音；不保存跨裝置進度；不提供教師後台。AI 實際呼叫需使用者自己的有效金鑰與網路，交付時未使用付費金鑰測試。核心離線流程另外進行自動化驗證。
