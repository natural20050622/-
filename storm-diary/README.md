# 風暴日記 · The Storm Diaries

以 Three.js 製作的國中英語 Lesson 5 沉浸式閱讀遊戲，優先支援平板與手機。

## 執行

安裝 Node.js 後，在本資料夾執行 `node server.mjs`，開啟 http://localhost:4173 。同一個 Wi-Fi 下，手機可用電腦的區域網路 IP 加上 `:4173` 開啟（需系統防火牆允許）。不要以 file:// 直接開啟 index.html。

## 遊戲內容

- 颱風公寓、曼谷餐廳兩個 3D 場景，可隨時切換。
- 拖曳旋轉、雙指縮放、點選場景標記或探索清單。
- 8 個探索點、16 題閱讀與文法練習，答錯可重新嘗試，提供課文證據與解析。
- 中文切換、單字解釋與搜尋、英文朗讀（依裝置語音支援）、減少動態。
- 瀏覽器本機儲存進度、下載文字學習紀錄、確認後清除進度。
- WebGL 不支援時仍可從清單閱讀及答題。

## 資料與原始碼

`dist/content.js` 儲存課文段落、中文、任務與題目；依專案內 7 張教材照片整理。練習題為教材知識點的情境化改編。場景為藝術化重現，不是防災操作訓練。

`dist/scene.js` 建立 Three.js 幾何場景與觸控視角；`dist/app.js` 管理閱讀、作答和本機紀錄；`dist/style.css` 提供響應式版面。

Three.js 0.170.0 已保存在 `dist/vendor`，MIT 授權。字型使用 Google Fonts，無網路時退回系統字型。遊戲不蒐集姓名或傳送作答資料；進度僅保存在目前瀏覽器，不會跨裝置同步。
