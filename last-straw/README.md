# 最後一根吸管 · The Last Straw

國中英語 Lesson 6 第一人稱 Three.js 沉浸式閱讀遊戲。

學生入口：https://natural20050622.github.io/-/last-straw/dist/

四章故事、16 段閱讀、14 個故事任務、40 個教材字詞、20 題教材練習。依使用者提供的教材照片製作；教材節錄與遊戲新增文字個別標示。

WASD／方向鍵移動，拖曳畫面觀看；靠近標記按 E 閱讀，或使用「帶我前往」。J 開啟閱讀手帳。進度保存在個別瀏覽器，可下載學習紀錄。操作說明中的「重新開始故事」可重設進度。

網站為靜態前端，Three.js r170 與 MIT 授權隨附於 vendor。字型無法載入時退回系統字型。沒有學生帳號、後端或對外寄信。

本機已測四章通關、進度續接、代表性教材練習、詞塊重組、鍵盤與拖曳操作及紀錄下載。實體手機與學校電腦仍待實測。
